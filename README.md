# inst_search

**inst_search** — инструмент командной строки на Python для поиска и анализа контента в YouTube и Instagram. Он помогает разработчикам и студиям находить авторов, которые продвигают услуги через видео, и выбирать форматы для своего контента.

## Что делает проект

- **Собирает публикации.** Ищет видео на YouTube по запросам из `queries.yaml` и собирает Shorts с выбранных каналов. Для Instagram ищет публикации по хэштегам и загружает профили и Reels через Apify.
- **Оценивает признаки лидогенерации.** Ищет в описаниях ссылки на формы и календари, предложения услуг и призывы написать в директ. По этим сигналам присваивает авторам оценку от 0 до 100.
- **Сравнивает форматы.** Группирует публикации по типу контента и помогает сравнить их по медиане просмотров с учётом размера аудитории.
- **Сохраняет результаты.** Хранит собранные данные в локальной базе SQLite и формирует Markdown-отчёт с авторами, метриками и примерами для дальнейшего разбора.

Оценка лидогенерации показывает, насколько заметно автор предлагает свои услуги. Число заявок и продаж инструмент не измеряет.

Примеры разбора форматов и выводы исследования собраны в [docs/REFERENCE.md](docs/REFERENCE.md).

## Установка

Нужен Python 3.12. Установите зависимости из корня проекта.

```powershell
py -3.12 -m pip install -r requirements.txt
```

## Источники данных

| Источник | Что даёт | Стоимость | Ключ |
|---|---|---|---|
| yt-dlp | поиск по YouTube, ленты каналов, подписчики, био канала | бесплатно, без квоты | не нужен |
| YouTube Data API v3 | полные описания, лайки, комментарии | 1 юнит на 50 видео (квота 10 000/сутки) | `YOUTUBE_API_KEY` |
| Apify `apify/instagram-scraper` | посты и reels по хэштегам, профили, метрики | ~$2.7/1000 результатов, $5 кредитов в месяц бесплатно | `APIFY_TOKEN` |

Почему Instagram платный: публичный веб-эндпоинт Instagram с чистого IP отдаёт 429,
а `instaloader` и `instagrapi` требуют аккаунт и рискуют его баном. Apify держит пул
прокси и логина не требует.

Почему поиск по YouTube не через официальный API: `search.list` стоит 100 юнитов за
запрос, то есть вся дневная квота уходит за 100 поисков. yt-dlp делает то же бесплатно.
Официальный API используем только там, где он дёшев: пакетное обогащение по 50 объектов
за 1 юнит.

```powershell
setx YOUTUBE_API_KEY "..."   # опционально
setx APIFY_TOKEN "..."       # нужен для Instagram
```

## Как пользоваться

```powershell
# 1. Собрать выдачу YouTube по всем запросам из queries.yaml
py -3.12 -m inst_search yt-discover --limit 25

# только шортсы, только русскоязычные группы запросов
py -3.12 -m inst_search yt-discover --group sell_services_ru teardown_ru --shorts

# разовый запрос без файла
py -3.12 -m inst_search yt-discover --query "ai automation agency clients" --limit 40

# 2. Профилировать найденные каналы: подписчики, био, медиана просмотров, лидген-скор
py -3.12 -m inst_search yt-channels --top 70

# 3. Забрать Shorts с вкладок отобранных каналов (см. оговорку ниже)
py -3.12 -m inst_search yt-shorts --top 30 --min-score 35

# 4. Пересчитать скоры после правки правил в scoring.py, без обращений к сети
py -3.12 -m inst_search rescore

# 5. Опционально: полные описания через официальный API
py -3.12 -m inst_search yt-enrich --top 500

# 6. Instagram (нужен APIFY_TOKEN)
py -3.12 -m inst_search ig-check                      # токен и остаток кредитов, бесплатно
py -3.12 -m inst_search ig-discover --limit 30        # reels по хэштегам за последние 3 месяца
py -3.12 -m inst_search ig-profiles --top 25          # профили и их ленты reels

# 5. Аналитика
py -3.12 -m inst_search formats --platform youtube --lang ru
py -3.12 -m inst_search report --top 40 --max-followers 200000 --print
py -3.12 -m inst_search stats
```

## Что означает лидген-скор

0-100, сумма весов найденных сигналов воронки (`inst_search/scoring.py`):

- 30 - ссылка на календарь (Calendly, Cal.com, TidyCal);
- 28 - прямой призыв записаться на созвон;
- 22 - прямое предложение услуг ("we build", "нужен сайт");
- 20 - заявочная форма (Typeform, Tally);
- 18 - DM-воронка ("напиши слово в директ");
- 15 - автор представляется владельцем агентства;
- 12 - лид-магнит в обмен на контакт;
- минус за признаки чисто медийной монетизации (спонсорские интеграции).

Скор от 50 - автор явно продаёт услуги через контент, это готовый референс воронки.
Скор ниже 25 - медиа или образование, копировать их формат для получения клиентов бесполезно.

Полезный фильтр в отчёте: `--max-followers 200000`. Каналы-миллионники живут по другим
законам (у них команда и другая экономика), а авторы на 10-100k подписчиков показывают
воспроизводимую воронку.

## Instagram: пошагово

1. Зарегистрируйся на [apify.com](https://apify.com) (free-план, карта не нужна).
2. Settings -> API & Integrations -> Personal API tokens, скопируй токен.
3. `setx APIFY_TOKEN "apify_api_..."` и перезапусти терминал.
4. `py -3.12 -m inst_search ig-check` - покажет остаток кредитов.
5. `py -3.12 -m inst_search ig-seed <хендлы...>` - засеять аккаунты, бесплатно.
6. `py -3.12 -m inst_search ig-profiles --top 25 --min-followers 3000` - профили и метрики.

Все платные команды печатают ожидаемый расход и отказываются работать, если он
превышает `--budget`. Расход считается по free-плану ($2.7 за 1000 результатов),
на платных планах результат дешевле, то есть оценка консервативная.

### Главный вывод по Instagram: посев работает, хэштеги нет

Проверено на практике. Хэштеги (`ig-discover`) приводят почти исключительно
студии-новички с 2-70 подписчиками: 239 собранных постов дали десятки аккаунтов,
из которых крупнее 2500 подписчиков не оказалось почти никого. Как референс они
бесполезны, а платить за их ленты приходится по полной.

Рабочая схема - `ig-seed` с готовым списком хендлов, найденных обычным поиском по
`site:instagram.com`, плюс `ig-profiles` с порогом `--min-followers`. Порог экономит
деньги напрямую: карточка профиля стоит 1 результат, лента - 15, и лента запрашивается
только у тех, кто порог прошёл.

Ещё одна ловушка актора: `searchType=hashtag` возвращает не посты, а карточки
найденных тегов, и промахивается по названию (запрос `vibecoding` вернул тег
`vibetheoryai`). Поэтому провайдер ходит по прямому URL `explore/tags/<тег>/`.

## Ограничения, о которых стоит помнить

**Shorts нельзя мерить поиском.** Поисковая выдача YouTube для коротких роликов
не отражает их реальные охваты: шортсы расходятся лентой Shorts, а не поиском.
Поэтому команда `yt-discover --shorts` даёт заниженные цифры, а честные берутся
через `yt-shorts`, который читает вкладку `/shorts` конкретного канала.

**Русскоязычный сегмент требует API-ключа для точного скоринга.** Англоязычные авторы
держат CTA в шапке канала, и yt-dlp её отдаёт. Русскоязычные держат воронку в описаниях
видео (обычно ссылка в Telegram), а yt-dlp в поиске отдаёт описание обрезанным до
~100 символов. Полные описания даёт только `yt-enrich` с `YOUTUBE_API_KEY`.

**yt-dlp не отдаёт блок «Ссылки» канала.** Ни yt-dlp, ни Data API v3 не возвращают
ссылки из отдельного блока на странице канала, только текст описания. Часть воронок
живёт именно там и в скоринг не попадает.

**Скоринг ищет признаки, а не читает смысл.** Возможны ложные срабатывания
(упоминание чужого домена засчитывается как своя ссылка). Финальный отбор
референсов делается глазами по `data/report.md`.

## Структура

```
inst_search/
  cli.py                  команды
  store.py                SQLite (videos, channels)
  scoring.py              лидген-скор, классификация форматов, язык
  providers/
    yt_ytdlp.py           поиск и ленты YouTube без ключа
    yt_api.py             пакетное обогащение через Data API v3
    ig_apify.py           Instagram через Apify
queries.yaml              поисковые запросы (главный рычаг качества выборки)
data/leadgen.db           база
data/report.md            markdown-отчёт по референсам
docs/REFERENCE.md         что снимать: форматы, хуки, CTA, метрики
```

## Расширение

Качество результата на 80% определяется `queries.yaml`. Если выборка получается
шумной, сужай запросы к своей вертикали: не "разработка сайтов", а "crm для
автосервиса", "автоматизация записи клиентов" - тогда найдутся не коллеги, а те,
кто продаёт именно тем клиентам, которые нужны тебе.
